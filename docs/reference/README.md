# reference/

Reference material that is **not** a specification. Files here are for quick lookup and
orientation. They are explicitly **non-authoritative** — when reference content disagrees with a
spec in [`../specs/`](../specs/), the spec wins.

## What Belongs Here

- Consolidated "deep dive" guides that restate content already specified elsewhere
- Cross-cutting overviews kept for convenience
- Any document that duplicates spec content for readability rather than defining it

## What Does Not Belong Here

- Authoritative specifications → [`../specs/`](../specs/)
- Architecture decisions → [`../adr/`](../adr/)
- Plans, research → [`../plans/`](../plans/), [`../research/`](../research/)
